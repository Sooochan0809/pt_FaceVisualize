# Lenticular Image Maker

外部ライブラリ不要で動作する、ブラウザ用レンチキュラー元画像生成ツールです。

## 起動方法

`index.html` をChromeなどのブラウザで開きます。

ローカルサーバーを使う場合：

```bash
cd lenticular-maker
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 主な機能

- 最大7枚の画像読み込み
- 小数第3位までのLPI入力
- A4、A3、はがき、カスタム用紙サイズ
- 72〜1200 PPI
- 縦レンズ／横レンズ
- 位相調整
- 画像順の反転
- cover／contain／stretch
- プレビュー生成
- 実寸PNG書き出し
- LPIピッチテスト生成

## 印刷時の注意

- 印刷倍率は100%にする
- 「用紙に合わせる」「ページに収める」を無効にする
- プリンター側のフチなし拡大補正に注意する
- 公称LPIではなく、ピッチテストで得た実測LPIを使用する

## 処理方式

各出力ピクセルについて、以下の考え方でレンズ内位相を計算します。

```js
const lensPosition = axis * lpi / ppi;
const phase = ((lensPosition + phaseOffset) % 1 + 1) % 1;
const imageIndex = Math.floor(phase * imageCount);
```

レンズ1本の幅を整数ピクセルに丸めないため、`40.125 LPI`などの小数値をそのまま扱えます。

## メモリ

A4・600PPIは約4961×7016pxです。画像7枚を展開するため、実寸書き出し時はブラウザのメモリを多く使用します。動作が重い場合は、まず300PPIまたは小さい用紙サイズで検証してください。

## サンプル画像

`sample-images` フォルダに動作確認用の画像が3枚あります。実際の制作では、同じ縦横比・同じ被写体位置に揃えた画像を使うと位置ずれが少なくなります。
